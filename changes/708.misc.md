Drop the `sonar-plugin-api-impl` test dependency

SonarQube 26.7 removed the `org.sonar.api.batch.**` classes from `sonar-plugin-api-impl`, which
broke `CpdTokenSaverTest`. The test now uses local test doubles, and both the
`sonar-plugin-api-impl` and `sonar-testing-harness` test dependencies are dropped.
