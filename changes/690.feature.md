Add a `#DEBUG` transmit mode to the VSCode extension

When enabled, a line whose first non-whitespace is `#DEBUG` has that marker stripped before
transmitting, so the line is compiled instead of staying a comment. Toggle it with the
`Magik: Toggle #DEBUG transmit` command (`f4 d`), the status bar indicator, or the
`magik.session.transmitDebug` setting. This mirrors emacs magik-mode.
