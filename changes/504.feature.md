Add SARIF output format to `magik-lint` and `magik-typed-lint`.

Both linters now accept a `--format sarif` option that emits a
[SARIF 2.1.0](https://docs.oasis-open.org/sarif/sarif/v2.1.0/sarif-v2.1.0.html)
document to stdout instead of the default line-per-issue format. The SARIF
output includes rule metadata (id, name, severity, tags), per-issue results
with message, level, and physical location (file URI, line/column range).

The reporter classes (`Reporter`, `NullReporter`, `MessageFormatReporter`,
`SarifReporter`) are now consolidated in the `magik-checks` module and
shared by both linters; the previously duplicated `output` packages in
`magik-lint` and `magik-typed-lint` have been removed.
