Judge a global reference in `DeprecatedTypeUsage` by its own pragma, not its value's.

The check used to look up the exemplar a reference evaluates to. As a result, a
deprecated global or procedure was never reported, while a global merely holding an
instance of a deprecated exemplar was.

A global reference is now resolved by name to the exemplars, procedures and globals it
names, and their own pragmas are checked. The message names the kind of definition,
e.g. "Used global 'user:!g!' is deprecated". A variable holding an instance of a
deprecated exemplar is no longer reported, as it does not reference the exemplar by name.
