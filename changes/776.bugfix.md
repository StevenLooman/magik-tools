Count comments after the last token of a file as comment lines.

Comments at the end of a file, including a comment on the last line of code, were not
counted. This affects the comment lines reported to SonarQube for Magik, `product.def`,
`module.def` and `load_list.txt` files, and the `CommentRatio` check. The reported
number of comment lines, and with it the comment density, can go up for existing files.

A file containing only comments is still regarded as having only a header comment.
