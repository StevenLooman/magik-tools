When a block-like expression (`_if`, `_try`, `_block`, `_loop`, `_for`, `_over`,
`_while`, `_protect`, `_catch`, `_lock`) uses `>>` in one or more of its bodies,
it produces a value.
Discarding that value without consuming it is an issue.
To fix it, assign, emit or return it.

Adding a new MagikCheck (`UnusedExpressionResult`) to cover this.
