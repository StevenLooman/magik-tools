Expand environment variables in definition/implementation/reference locations sent to the client.

Locations coming from a dumped type database record their source path with a logical such as
`$SMALLWORLD_GIS`, which the editor cannot open. Any `$NAME` in such a path is now expanded when
the location is handed to the client, taking its value from the process environment, with
`$SMALLWORLD_GIS` additionally taking the `magik.smallworldGis` setting when that is set; a
variable that resolves to nothing is left literal, and the stored location keeps its literal,
installation-independent URI. A location which only names a file, without a position in it, is
also dropped when another source provides the same file with an actual position, removing the
duplicate entry shown for a definition; multiple hits in a single file, as returned by
`references`, are kept.
