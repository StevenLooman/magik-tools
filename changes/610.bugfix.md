Fix the `magik.formatting.indentStrategy` setting and restore the older strategy
values for backwards compatibility.

The setting's advertised values were out of sync with the strategies the
formatter recognised, so the `magik.formatting.indentStrategy` enum now offers
`block`, `null`, `relative` and `visual`. The previously supported `relative`
value is mapped again (to the visual indent strategy), so existing
configurations keep working instead of silently falling back to the default.

Configuring an unknown indent strategy no longer crashes the language server
with a stack trace. Formatting now falls back to the default strategy (and logs
a warning), while the `Formatting` check reports the misconfiguration as a
diagnostic. The message names the setting, lists the allowed values (`block`,
`null` and `visual`) and, when the value looks like a typo, suggests the closest
match (e.g. `"visua"` -> did you mean `"visual"`).
