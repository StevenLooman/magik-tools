Add the `_invokable` type to describe callback contracts in type docs.

A callback's signature is carried by generics: `P=[...]` for its parameters,
`R=[...]` for its results and `L=[...]` for its loop types, e.g.
`_invokable<P=[_self]>`. A method can refer to a callback's results via
`_parameter(a_proc)<R>`. Malformed type strings now resolve to `_undefined`
instead of silently dropping the unparsed remainder.
