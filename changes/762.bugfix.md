Dump the `location` of method and procedure definitions in `sw_type_dumper`.

`sw_type_dumper` used to dump a `source_file` for method and procedure definitions,
which is not read from the types database. It now dumps a `location` with a
`file://` URI instead, so the source file of these definitions is known. Windows
paths are converted and a leading `$SMALLWORLD_GIS` logical is kept.

Breaking changes:

The `source_file` field is replaced by `location` in the dumped types database.
Re-dump the types database with the current `sw_type_dumper` to get the locations.
