Harden the GitHub Actions workflows, checked by a new zizmor workflow.

Actions are pinned to commit SHAs, every job gets only the permissions it needs, and the third-party
actions for codespell, markdownlint, the wiki and releases are replaced by hash- or lockfile-pinned
tools and `gh`. Release builds no longer use a cache, and the SonarCloud token moves to a
`sonarcloud` environment restricted to `develop`.
