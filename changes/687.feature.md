Update the Magik TextMate grammar

The TextMate grammar used by the VSCode extension for syntax highlighting, before the language
server has analyzed the file, is now taken from
[magik.tmLanguage](https://github.com/StevenLooman/magik.tmLanguage/). It recognizes character
literals, numbers, `!globals!`, labels and global references, `FIXME`/`TODO`/`DEBUG` markers, and
TypeDoc annotations within `##` comments, and scopes keywords, operators, method definitions and
method calls closer to what MagikGrammar accepts.
