Report `@return`/`@loop` entries that carry no type.

The type is optional in the type-doc grammar, so `## @return` parses successfully and was then
silently discarded before any type comparison happened. `CallableReturnTypesMatchDoc` and
`IterCallableYieldTypesMatchDoc` now report such entries. This is easy to hit by accident: a wrapped
description line that begins with a tag name parses as a second, untyped declaration of that tag,
and nothing warned about it.
