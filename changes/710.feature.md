Read procedures and type docs from class-info

Definitions read from class-info now carry the types declared in their own documentation. The
`##` comment recorded for a method, procedure, global or exemplar is run through the type-doc
parser, so its `@param`, `@return`, `@loop` and `@slot` declarations type the parameters, the
return and loop results, and the exemplar's slots, instead of everything being `UNDEFINED`. A
global's aliased type is taken from its `@return` declaration.

A global record which carries parameters or an `iter` marker is a procedure bound to that name,
and is now indexed as a `ProcedureDefinition` -- with its parameters, its `iter` modifier and its
type doc -- rather than being recorded as a plain global with its parameters discarded.
