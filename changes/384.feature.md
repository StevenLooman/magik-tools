Add checks for `pragma`'s to verify that the module name and product name
of the source file are in the topics of the `pragma`.

The following checks have been added for `magik` files:

- `PragmaTopicsDoesNotIncludeModuleName`/`pragma-topics-does-not-include-module-name`
- `PragmaTopicsDoesNotIncludeProductName`/`pragma-topics-does-not-include-Product-name`

Both checks are disabled by default to prevent raising a lot issues in your codebase.
