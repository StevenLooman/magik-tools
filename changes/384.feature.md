Add checks for `pragma`'s to verify that the mandatory topics are included.
The mandatory topics can be any of:

- module name
- product name
- list of topics

The following checks have been added for `magik` files:

- `PragmaDoesNotIncludeMandatoryTopic`/`pragma-does-not-include-mandatory-topic`

The check is enabled, but checking of the module name/product name is included
is disabled, and the list of topics is also empty.
