Some rule-description HTML files use markup that breaks the render once it is used on the GitHub wiki and in SonarQube.

- `<pre>` used for inline code instead of `<code>`, `<pre>` is block-level, so on the wiki it shreds a sentence into separate orphaned code blocks.
- Nested `<pre><pre>...</pre></pre>` in code examples.
- Missing short first-paragraph summary - without it, the whole multi-sentence description gets pulled into the page's `<h1>`/title.
- Stray duplicate `<h2>` heading + typo in `ForbiddenInheritance.html` ("to in herit").
