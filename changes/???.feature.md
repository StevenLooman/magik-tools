`product.def` is now checked, like magik files. Issues will be raised dependent
on the quality of these files on your codebase and your configuration.

## Breaking changes

This change includes a major refactoring, such as moving classes to different
namespaces, and rebuilding support classes. Any code dependent on this code will
have to follow these changes.

Furthermore, `product.def` is now checked as well. This might result in new
issues in your codebase.
