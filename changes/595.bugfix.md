Improve how a type or global reference resolves, fixing false `Unknown method`
diagnostics from type-aware features such as the `method-exists` check.

A reference now resolves to the single type defined in the nearest package,
instead of a union of same-named types across the package-use hierarchy: a
reference defined in the current package shadows a same-named definition in a
`uses`d package. Previously the union made the `method-exists` check report a
false `Unknown method` for the unrelated package's member, even while hover
showed the method's documentation.

A reference to a `_global` now evaluates to the global's aliased type (e.g. its
`# type:` declaration) instead of the global's own name. Because a `_global` is
an alias, its own name has no methods, so every call on it was previously
reported as an unknown method. This also applies when the aliased type is a
union (e.g. `# type: sw:rope|sw:unset`).
