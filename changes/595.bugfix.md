Resolve a type or global reference to the single type defined in the nearest
package, instead of a union of same-named types across the package-use
hierarchy.

A reference defined in the current package now shadows a same-named definition
in a `uses`d package. Previously the reference resolved to a union of both,
which made type-aware features such as the `method-exists` check report a false
`Unknown method` diagnostic for the unrelated package's member, even while hover
still showed the method's documentation.
