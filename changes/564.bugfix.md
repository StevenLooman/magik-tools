Resolve `_parameter(<name>)` references in `return_types` and `loop_types` for
assignment-method invocations such as `a[k] << v` and `a.foo << v`.

The parameter reference is substituted with the corresponding argument's type
at the call site, including for the assignment parameter (the right-hand side
of the assignment). Previously these substitutions only happened for ordinary
method calls; assignment-method calls produced `UNDEFINED` when a
`_parameter(<name>)` reference was used.
