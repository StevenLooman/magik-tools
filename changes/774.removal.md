**Breaking change**: Rename the `whitelist` property of `VariableNaming` to `exceptions`.

This is consistent with the `exceptions` property of other checks, such as `MagicNumber`
and `ExemplarFileNameMismatch`. Update any configuration setting
`variable-naming.whitelist` to `variable-naming.exceptions`; the old property is no
longer read.

Spaces around the listed names are now ignored, so `x, y, z` works as well as `x,y,z`.
