Add checks `EmitInLoop`, `EmitOrLeaveResultUnused`, `LeaveInProtection`, `FinallyWithRequiresOver`.

A description of the checks:

- `EmitInLoop`: flags an emit statement (`>>`) directly in a loop body, where it has no effect.
- `EmitOrLeaveResultUnused`: flags an emit or `_leave _with` statement whose result is discarded.
- `LeaveInProtection`: flags `_leave`/`_leave _with` inside a `_protection` block, which results in a compiler error.
- `FinallyWithRequiresOver`: flags a `_finally _with var` clause on a loop without an `_over` parent.
