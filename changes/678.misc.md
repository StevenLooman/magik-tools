Modularize `CallHierarchyProvider`

`prepareCallHierarchy` now runs a set of modules, one for method definitions and one for procedure
definitions, instead of a single branching method, mirroring the other modularized providers'
structure. The unrelated `callHierarchyIncomingCalls`/`callHierarchyOutgoingCalls` call-graph
lookups were left untouched.
