Improvements to magik-debug-adapter

Many improvements to:

- transport: long replies, end of stream, handshake, skip
  unhandleable messages, fail the request of an undecodable reply
- early requests
- unknown breakpoint ids
- pausing of a suspended thread
- removing function breakpoints
- thread safety
- variables view: collection elements and paging, and a pluggable
  expansion framework in its own `variables` package
- a stepping seam whose basic module is the original stepping
- README: agent port syntax, default port, access, known limitations.
