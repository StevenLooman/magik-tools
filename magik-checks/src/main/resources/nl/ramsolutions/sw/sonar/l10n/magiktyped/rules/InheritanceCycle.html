Inheritance cycle

Explanation

def_slotted_exemplar(:child, {}, :parent)
$

def_slotted_exemplar(:parent, {}, :child)
$

In the above example, child inherits from parent, and parent inherits from child. This cycle can be spread across separate files/modules, so neither file necessarily looks wrong on its own. A type cannot legitimately inherit from itself, directly or indirectly; resolving methods/slots for either type is undefined.
