Pragma contains an invalid usage.

Non-compliant Code Example

_pragma(classify_level=basic, topic={example}, usage=invalid)
_method object.do_something()
_endmethod

Compliant Code Example

_pragma(classify_level=basic, topic={example}, usage=redefinable)
_method object.do_something()
_endmethod

The usage should be one of:

  • subclassable
  • subclass
  • redefinable
Other known, but to be ignored, usages are:
  • external
  • internal
