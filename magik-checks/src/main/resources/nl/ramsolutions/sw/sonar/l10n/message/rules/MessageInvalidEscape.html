Message text has an invalid parameter or special character.

Description

A # in the text of a message starts a parameter (#1 to #9, #@1 or #h1) or a special character: ## for a #, #n for a newline, #t for a tab and #s for a space.

Any other # is silently left out of the text, together with the character following it. The parameter #0 does not exist and raises an error when the message is used. Use ## to get a # in the text.

Non-compliant Code Example

:number_of_pipes Pipe # #1 of #0

Compliant Code Example

:number_of_pipes Pipe ## #1 of #2
