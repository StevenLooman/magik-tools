When a block-like expression (_if, _try, _block, _loop, _for, _over, _while, _protect, _catch, _lock) uses >> in one or more of its bodies, it produces a value.

Discarding that value without consuming it is almost certainly a bug. Assign it, emit it, or return it.

Non-compliant Code Example

_if condition
_then
    >> _true
_else
    >> _false
_endif

_try >> _true _when error >> _false _endtry

_block >> computed_value _endblock

Compliant Code Example

result << _if condition
_then
    >> _true
_else
    >> _false
_endif

result << _try >> _true _when error >> _false _endtry

result << _block >> computed_value _endblock
