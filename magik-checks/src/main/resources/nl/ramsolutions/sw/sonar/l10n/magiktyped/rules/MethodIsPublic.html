Method Is Public

Non-compliant Code Example

_private _method example_exemplar.private_example_method()
    ## Private method which cannot be called from other methods or blocks.
_endmethod
$

_block
    example_exemplar.private_example_method()
_endblock
$

Compliant Code Example

_private _method example_exemplar.private_example_method()
    ## Private method which cannot be called from other methods or blocks.
_endmethod
$

_method example_exemplar.example_method()
    _self.private_example_method()
_endmethod
$

The call to example_exemplar.private_example_method() will result in an error, because the method is private and cannot be called from outside its own definition. A method of example_exemplar may call it on _self.
