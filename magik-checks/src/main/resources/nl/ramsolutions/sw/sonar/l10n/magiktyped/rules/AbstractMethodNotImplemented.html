Abstract method not implemented

Explanation

_abstract _method parent.do_something()
    ## @return {integer}
_endmethod

_method child.other_method()
    _return 1
_endmethod

In the above example, 

child
inherits from 
parent
which defines an abstract method 
do_something()
. Since 
child
does not implement this method, calling it will result in a runtime error.
