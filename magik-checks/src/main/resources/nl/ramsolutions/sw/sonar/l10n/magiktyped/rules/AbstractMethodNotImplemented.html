Abstract method not implemented

Non-compliant Code Example

_abstract _method parent.do_something()
    ## @return {integer}
_endmethod
$

def_slotted_exemplar(:child, {}, :parent)
$

Compliant Code Example

_abstract _method parent.do_something()
    ## @return {integer}
_endmethod
$

def_slotted_exemplar(:child, {}, :parent)
$

_method child.do_something()
    ## @return {integer}
    _return 1
_endmethod
$

In the above example, child inherits from parent which defines an abstract method do_something(). Since child does not implement this method, calling it will result in a runtime error.
