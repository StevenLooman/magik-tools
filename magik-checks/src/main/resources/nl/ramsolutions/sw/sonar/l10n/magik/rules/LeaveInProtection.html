A _leave or _leave _with statement inside a _protection block is a runtime error in Magik. The Magik compiler raises: Cannot leave from protection.

Use _leave only inside _protect body, _loop, or other constructs that support it. The _protection block is a cleanup/finally clause and does not support early exit via _leave.

Non-compliant Code Example

_protect
  do_something()
_protection
  _leave  # Compiler error: Cannot leave from protection
_endprotect

Compliant Code Example

_protect
  _leave  # valid: _leave in the protect body
_protection
  cleanup()
_endprotect
