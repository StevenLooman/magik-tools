load_list.txt or patch_list.txt contains an entry that does not exist on the filesystem.

Description

All entries in a load list should reference existing files or directories. File entries should point to existing .magik files, and directory entries (ending with /) should point to existing directories that contain a load_list.txt file.

Non-compliant Code Example

# Load list with non-existent entries
file1.magik
missing_file.magik
nonexistent_subdir/
subdir_without_loadlist/

Compliant Code Example

# Load list with valid entries
file1.magik
file2.magik
subdir/

Notes

  • File entries should reference existing .magik files relative to the load_list.txt directory
  • Directory entries (ending with /) should reference existing directories that contain a load_list.txt file
