Translation has fields which are ignored.

Description

Smallworld silently ignores any field after the translated text. This most likely is a mistake, such as a missing line break between two translations.

Non-compliant Code Example

external_name	pipe	unset	en_gb	Pipe	Water pipeexternal_name	valve	unset	en_gb	Valve	Water valve

Compliant Code Example

external_name	pipe	unset	en_gb	Pipe	Water pipe
external_name	valve	unset	en_gb	Valve	Water valve
