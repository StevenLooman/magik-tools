Use of sw:char16_vector.evaluate()

Non-compliant Code Example

_block
    _local user_input << "gis_program_manager.cached_dataset(:gis).collection(:very_important_data).empty()"
    user_input.evaluate()
_endblock

Compliant Code Example

_block
    _local user_input << "very_important_data"
    gis_program_manager.cached_dataset(:gis).collection(user_input.as_symbol())
_endblock

The example shows the use of sw:char16_vector.evaluate() to execute user input as Magik code. This is dangerous as it can lead to code injection vulnerabilities if the user input is not properly sanitized. Taking only a name from the user, and using it as data, resolves it.
