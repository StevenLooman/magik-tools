Pragma contains an invalid classify_level.

Non-compliant Code Example

_pragma(classify_level=invalid, topic={example}, usage=redefinable)
_method object.do_something()
_endmethod

Compliant Code Example

_pragma(classify_level=basic, topic={example}, usage=redefinable)
_method object.do_something()
_endmethod

The classify_level should be one of:

  • basic
  • advanced
  • restricted
  • debug
  • deprecated
