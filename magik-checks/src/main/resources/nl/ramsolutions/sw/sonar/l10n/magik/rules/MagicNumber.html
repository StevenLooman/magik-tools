A magic number is a numeric literal that is used in code without being declared as a constant.

Magic numbers can make code difficult to read and maintain because their meaning and purpose are not explicit. Declare magic numbers as constants or named variables to give them meaningful names.

Non-compliant Code Example

_method my_exemplar.calculate_total(price)
    _return price * 1.21  # magic number
_endmethod

Compliant Code Example

my_exemplar.define_shared_constant(:vat_rate, 1.21, :private)
$

_method my_exemplar.calculate_total(price)
    _return price * _self.vat_rate
_endmethod
