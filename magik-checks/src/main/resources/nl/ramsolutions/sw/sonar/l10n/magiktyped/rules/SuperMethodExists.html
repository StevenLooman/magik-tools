Super method exists

A plain _super.m() is bound, when its method is loaded, to the one direct parent that answers m(). The method fails to load when no parent answers m(), or when two or more parents do.

When two or more parents answer the method, the send is reported as Too many super implementations of m(). Name the parent to call instead, as in _super(mixin_a).m(); such a send is reported when the named parent does not answer the method.

Non-compliant Code Example

def_slotted_exemplar(:parent, {})
$

_method parent.do_something()
_endmethod
$

def_slotted_exemplar(:child, {}, {:parent})
$

_method child.do_something()
    _super.nonexistent()
_endmethod
$

Compliant Code Example

def_slotted_exemplar(:parent, {})
$

_method parent.do_something()
_endmethod
$

def_slotted_exemplar(:child, {}, {:parent})
$

_method child.do_something()
    _super.do_something()
_endmethod
$

Non-compliant Code Example

def_mixin(:mixin_a)
$

_method mixin_a.do_something()
_endmethod
$

def_mixin(:mixin_b)
$

_method mixin_b.do_something()
_endmethod
$

def_slotted_exemplar(:child, {}, {:mixin_a, :mixin_b})
$

_method child.do_something()
    _super.do_something()
_endmethod
$

Compliant Code Example

def_mixin(:mixin_a)
$

_method mixin_a.do_something()
_endmethod
$

def_mixin(:mixin_b)
$

_method mixin_b.do_something()
_endmethod
$

def_slotted_exemplar(:child, {}, {:mixin_a, :mixin_b})
$

_method child.do_something()
    _super(mixin_a).do_something()
_endmethod
$
