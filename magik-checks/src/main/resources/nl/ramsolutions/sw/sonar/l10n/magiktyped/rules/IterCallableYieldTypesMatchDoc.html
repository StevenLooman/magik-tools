Iter callable yield types match doc

Explanation

Verifies that the @loop type annotations in an iter callable's documentation match its reasoned _loopbody yield types. Issues are raised in the following situations:

  • A @loop annotation is missing on an iter callable that yields values.
  • A @loop annotation is present on a non-iter callable.
  • A @loop type does not match the reasoned yield type.
  • A @loop annotation carries no type at all.

Yield slots whose type is unknown (e.g. from an unresolved method call) are skipped for mismatch reporting; those are covered by UndefinedMethodCallResultTypedCheck.

Type mismatch: the callable is documented to yield float but actually yields integer.

Non-compliant Code Example

_iter _method example_exemplar.example_method()
    ## @loop {float}
    _loopbody(1)
_endmethod

Compliant Code Example

_iter _method example_exemplar.example_method()
    ## @loop {integer}
    _loopbody(1)
_endmethod

Missing @loop: the iter callable yields a value but has no @loop annotation.

Non-compliant Code Example

_iter _method example_exemplar.example_method()
    _loopbody(1)
_endmethod

Compliant Code Example

_iter _method example_exemplar.example_method()
    ## @loop {integer}
    _loopbody(1)
_endmethod

@loop on non-iter callable: @loop is only valid on iter callables.

Non-compliant Code Example

_method example_exemplar.example_method()
    ## @loop {integer}
_endmethod

Compliant Code Example

_iter _method example_exemplar.example_method()
    ## @loop {integer}
    _loopbody(1)
_endmethod

@loop without a type: the type in a @loop annotation is optional in the grammar: the wrapped description line parses as a second, untyped @loop declaration. Untyped annotations are discarded before any type comparison, so without this check the mistake goes unnoticed while the callable is recorded as yielding two values. Wrapping the line elsewhere resolves it.

Non-compliant Code Example

_iter _method example_exemplar.example_method()
    ## @loop {integer} the value, which
    ## @loop must be yielded one at a time
    _loopbody(1)
_endmethod

Compliant Code Example

_iter _method example_exemplar.example_method()
    ## @loop {integer} the value, which @loop
    ## must be yielded one at a time
    _loopbody(1)
_endmethod
