Undefined method call result

Non-compliant Code Example

_method example_exemplar.example_method()
    _return 1
_endmethod
$

_block
    _local var << example_exemplar.example_method()
_endblock
$

Compliant Code Example

_method example_exemplar.example_method()
    ## @return {sw:integer} An example value.
    _return 1
_endmethod
$

_block
    _local var << example_exemplar.example_method()
_endblock
$

The example shows a call to a method for which the return types in the type-doc has not been defined. Add type-doc with the appropriate @returns to the method, or the type database.
