The source code should have enough comments to explain the logic.

The comment density is computed as: comment_lines / (lines_of_code + comment_lines).

Non-compliant Code Example

# only 10% comments
_method a.b()
    _local x << 1
    _local y << 2
    _local z << 3
    _local w << 4
    _return x + y + z + w
_endmethod

Compliant Code Example

# This method sums up the values
# and returns the result.
_method a.b()
    _local x << 1  # first value
    _local y << 2  # second value
    _local z << 3  # third value
    _local w << 4  # fourth value
    _return x + y + z + w
_endmethod
