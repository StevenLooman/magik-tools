Pragma does not contain all topics from the configured list in topics.

Given the next configuration:

pragma-does-not-include-topic-in-topics.topics=magik

Non-compliant Code Example

_pragma(classify_level=basic, topic={})
def_slotted_exemplar(:example, {})
$

Compliant Code Example

_pragma(classify_level=basic, topic={magik})
def_slotted_exemplar(:example, {})
$
