Variable definition hides another variable with the same name.

Non-compliant Code Example

_block
  _local x << 10
  _for i _over 1.upto(10)
  _loop
    _local x << 20
    show(x)
  _endloop
_endblock

Compliant Code Example

_block
  _local x << 10
  _for i _over 1.upto(10)
  _loop
    _local y << 20
    show(y)
  _endloop
_endblock
