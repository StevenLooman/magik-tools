Assigned type does not match slot type

Explanation

## Example exemplar.
## @slot {sw:rope} slot_1
def_slotted_exemplar(
        :example_exemplar,
        {
            {:slot_1, sw:rope}
        })

_method example_exemplar.example_method()
    ## This assignment will raise an issue, because slot_1 is declared as sw:rope, but we are assigning an sw:integer.
    .slot_1 << 12345
_endmethod
$

In the above example, in method example_exemplar.example_method(), we are trying to assign an integer value to a slot that is declared as a rope.
