Deprecated type usage

Non-compliant Code Example

_pragma(classify_level=deprecated)
## Example exemplar.
def_slotted_exemplar(
        :example_exemplar,
        {
        })
$

_block
    example_exemplar.example_method()
_endblock
$

Compliant Code Example

_pragma(classify_level=deprecated)
## Example exemplar.
def_slotted_exemplar(
        :example_exemplar,
        {
        })
$

_pragma(classify_level=basic)
## Replacement of example_exemplar.
def_slotted_exemplar(
        :new_example_exemplar,
        {
        })
$

_block
    new_example_exemplar.example_method()
_endblock
$

In the example, the use of example_exemplar is marked as deprecated, as the exemplar itself is marked as deprecated using the _pragma(classify_level=deprecated) directive.

A reference to a deprecated procedure or global is reported the same way. The pragma read is that of the name written: a global which is not deprecated but holds an instance of a deprecated exemplar is not reported, and neither is a local variable holding one.
