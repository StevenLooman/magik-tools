Ensure that no module listed in tests_modules also appears in requires. If a module is listed as tests_modules, it is already required implicitly. Adding it to requires is redundant.

Non-compliant Code Example

example_module_tests 1

requires
    example_module
end

tests_modules
    example_module
end

Compliant Code Example

example_module_tests 1

tests_modules
    example_module
end
