Translation (.trn) file contains a syntax error.

Description

A translation is a single line of fields which are separated by tabs: the type of the translation (enumerator, external_name or field_value), two keys, the language, the source text and the translated text. The language is left out in a file which is specific to a language, such as a file in resources/en_gb/translations.

A line is a syntax error when Smallworld cannot read it: a line with a translated text and an unknown type, a line without both keys, a line without a language where one is required, or a line of only spaces. Note that a line is only a comment if the # is the first character of the line. Smallworld stops reading the file at such a line: the translations after that line are not loaded.

Non-compliant Code Example

#% text_encoding = utf8
external_names	pipe	unset	en_gb	Pipe	Water pipe

Compliant Code Example

#% text_encoding = utf8
external_name	pipe	unset	en_gb	Pipe	Water pipe
