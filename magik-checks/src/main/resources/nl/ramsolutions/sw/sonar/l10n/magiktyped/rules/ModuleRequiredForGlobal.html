Module required for used global

Explanation

# Inside a module which does NOT require the appropriate module to get
# the test_exemplar_from_another_module global variable.
_block
    _local var << test_exemplar_from_another_module
_endblock
$

This will raise an issue, because the test_exemplar_from_another_module might not be loaded, as the module containing this example code does not require the module which supplies the test_exemplar_from_another_module.
