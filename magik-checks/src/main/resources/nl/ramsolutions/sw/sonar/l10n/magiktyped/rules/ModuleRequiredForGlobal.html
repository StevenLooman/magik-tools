Module required for used global

In the examples below, the global test_exemplar_from_another_module is defined in module another_module. Each example shows the module.def of the module and a source file in it, each introduced by a comment line naming the file.

Non-compliant Code Example

# example_module/module.def
example_module 1

description
	Example module
end

# example_module/source/example.magik
_block
    _local var << test_exemplar_from_another_module
_endblock
$

Compliant Code Example

# example_module/module.def
example_module 1

description
	Example module
end

requires
	another_module
end

# example_module/source/example.magik
_block
    _local var << test_exemplar_from_another_module
_endblock
$

This will raise an issue, because the test_exemplar_from_another_module might not be loaded, as the module containing this example code does not require the module which supplies the test_exemplar_from_another_module.
