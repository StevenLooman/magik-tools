An emit (>>) or _leave _with val statement produces a value, but the value is discarded because the containing construct is used as a standalone statement rather than an expression.

>> emits a value from the current scope to the parent scope. If that scope is a control structure used as a statement, the emitted value is discarded.

_leave _with val provides a value from a loop or block expression. If the loop or block is a standalone statement, the value is discarded.

Non-compliant Code Example

_method a.b
  _if condition?
  _then
    >> :a    # Result discarded
  _endif
_endmethod

_method a.b
  _loop _leave _with 42 _endloop  # Result discarded
_endmethod

Compliant Code Example

_method a.b
  >> _if condition?
  _then
    >> :a    # _if used as expression, result re-emitted
  _endif
_endmethod

_method a.b
  >> _loop _leave _with 42 _endloop  # Loop used as expression
_endmethod
