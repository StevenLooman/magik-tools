Message (.msg) file contains a syntax error.

Description

A message starts with its id, a symbol at the start of a line, followed by the text of the message. The text continues on the following lines, up to the next line which starts with a :. Before the first message, a line starting with # is a comment. A single line starting with +, which can only be preceded by comments, names the message files which are used as well.

A message with an invalid id, any other text before the first message or a second line starting with + is a syntax error. Smallworld cannot read a message file with a syntax error.

Non-compliant Code Example

#% text_encoding = utf8
Text without a message id
:1_invalid_id Text

Compliant Code Example

#% text_encoding = utf8
:message_id Text
:other_message_id
Text of #1,
on multiple lines
