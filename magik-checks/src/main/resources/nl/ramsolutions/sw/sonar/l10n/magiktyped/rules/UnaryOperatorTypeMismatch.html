Unary operator type mismatch

Explanation

_method a.b
    _local x << :symbol
    _local y << +x
_endmethod

In the above example, +x maps to the unary method unary_plus. When that method is not available for sw:symbol, the result type is undefined and can cause runtime failures.

_scatter x is not reported when for_scatter() of x declares a result: its values are then unknown only because the element type of x is.
