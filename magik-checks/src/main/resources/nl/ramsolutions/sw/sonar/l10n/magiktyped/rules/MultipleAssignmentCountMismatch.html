Multiple assignment count mismatch

Non-compliant Code Example

_method a.b
    (x, y, z) << (1, 2)
_endmethod

Compliant Code Example

_method a.b
    (x, y) << (1, 2)
_endmethod

In the above example, three variables are assigned from an expression that returns only two values. The third variable z will silently receive _unset.
