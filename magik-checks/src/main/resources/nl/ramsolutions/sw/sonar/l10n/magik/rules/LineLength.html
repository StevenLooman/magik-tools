Having to scroll horizontally makes it harder to get a quick overview and understanding of any piece of code.

By default, a line is reported when it is longer than 120 characters.

Non-compliant Code Example

_local message << write_string("Parcel ", parcel.id, " of owner ", parcel.owner, " has an area of ", parcel.area, " square metres")

Compliant Code Example

_local message << write_string("Parcel ", parcel.id, " of owner ", parcel.owner,
                               " has an area of ", parcel.area, " square metres")
