The _with clause of a _finally block is only supported when the loop has an _over parent. The variable in _with receives the value returned by the iterator call, so it has no meaning on a bare _loop.

Use a plain _finally (without _with) on loops that have no _over.

Non-compliant Code Example

_loop
  _if done?() _then _leave _endif
_finally _with x  # No _over: x has no value to receive
_endloop

Compliant Code Example

_over example.iterator_method()
_loop
  write(:a)
_finally _with x  # valid: x receives the returned value of example.iterator_method() result
_endloop
