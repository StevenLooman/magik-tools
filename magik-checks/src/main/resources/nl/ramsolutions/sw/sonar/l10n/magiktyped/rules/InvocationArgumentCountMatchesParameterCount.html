Invocation argument count matches parameter count

Non-compliant Code Example

_method a.m(param1, param2)
_endmethod
$

_block
    a.m(1)
_endblock
$

Compliant Code Example

_method a.m(param1, param2)
_endmethod
$

_block
    a.m(1, 2)
_endblock
$

The example above shows an invocation of a.m(), but is missing argument param2.
