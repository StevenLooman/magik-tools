Only a variable, a slot or a method call can be the target of an assignment. Smallworld refuses to compile an assignment to anything else, such as the result of a procedure call, a literal, _self or a calculation, so the file does not load.

The rule reports such a target in an assignment (<<, ^<<), in an augmented assignment such as +<<, and between the parentheses of a multiple assignment. A method call as target is not reported: a.x << 1 and a[1] << 1 send x<< and []<< to a.

Non-compliant Code Example

total << count() << 0
(first, rest()) << values()

Compliant Code Example

total << counter << 0
(first, rest) << values()
