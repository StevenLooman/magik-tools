Conditional expression does not result in true/false

Explanation

_if :a
_then
_endif

In the above Magik code snippet, the conditional expression :a does not explicitly evaluate to sw:true or sw:false. In Magik, conditional expressions should result in a boolean value (true or false), otherwise this will result in an error.

A type that responds to should_be_boolean() is also accepted, as Magik will use that method to coerce the value to a boolean.
