Conditional expression does not result in true/false

Non-compliant Code Example

_block
    _local mode << :edit
    _if mode
    _then
        write("Editing")
    _endif
_endblock

Compliant Code Example

_block
    _local mode << :edit
    _if mode _is :edit
    _then
        write("Editing")
    _endif
_endblock

In the above Magik code snippet, the conditional expression mode holds the symbol :edit, and does not explicitly evaluate to sw:true or sw:false. In Magik, conditional expressions should result in a boolean value (true or false), otherwise this will result in an error.

A type that responds to should_be_boolean() is also accepted, as Magik will use that method to coerce the value to a boolean.
