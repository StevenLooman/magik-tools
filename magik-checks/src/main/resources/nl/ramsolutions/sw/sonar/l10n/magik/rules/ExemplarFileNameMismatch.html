Exemplar related definitions (such as exemplar definitions and method definitions) should be in a file named *<exemplar_name>*.magik.

Non-compliant Code Example

# in file other.magik:
_method my_exemplar.my_method()
    _return 42
_endmethod

Compliant Code Example

# in file my_exemplar.magik:
_method my_exemplar.my_method()
    _return 42
_endmethod
