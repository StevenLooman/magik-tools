Deprecated method usage

Non-compliant Code Example

_pragma(classify_level=deprecated)
_method exemplar.example_method()
_endmethod
$

_block
    _local exem << exemplar
    exem.example_method()
_endblock
$

Compliant Code Example

_pragma(classify_level=deprecated)
_method exemplar.example_method()
_endmethod
$

_pragma(classify_level=basic)
_method exemplar.new_example_method()
_endmethod
$

_block
    _local exem << exemplar
    exem.new_example_method()
_endblock
$

In the example above, the method call exem.example_method() is marked as deprecated using the _pragma(classify_level=deprecated) directive. Calling its replacement new_example_method() resolves it.
