Invocation argument type does not match parameter type

Explanation

_method a.m(param1, param2)
    ## @param {sw:integer} param1
    ## @param {sw:integer} param2
_endmethod
$

_block
    a.m(1, :a)
_endblock
$

The invocation a.m() uses arguments of type sw:integer and sw:symbol, while the callable expects sw:integer twice, as documented.
