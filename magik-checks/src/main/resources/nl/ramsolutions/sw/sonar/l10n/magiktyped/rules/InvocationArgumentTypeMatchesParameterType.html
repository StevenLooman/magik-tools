Invocation argument type does not match parameter type

Explanation

_method a.m(param1, param2)
    ## @param {sw:integer} param1
    ## @param {sw:integer} param2
_endmethod
$

_block
    a.m(1, :a)
_endblock
$

The invocation a.m() uses arguments of type sw:integer and sw:symbol, while the callable expects sw:integer twice, as documented.

A union argument matches when any of its types matches the parameter type. An argument or parameter whose type is not known is not reported: an undefined or unresolvable type, a generic reference, a callback contract, or a union with such a type. In a method invocation, _self stands for the receiver.
