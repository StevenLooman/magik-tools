Variadic ('Type...') is only valid on @return or @loop

Explanation

The variadic marker ... describes "zero or more values of T". It is meaningful on @return (a method returning 0..N values) and on @loop (a _loopbody emitting 0..N values per iteration), such as ## @loop {sw:integer...} on an iter method, but not on @param or @slot.

Variadic on @param: declare the element type of a gathered parameter.

Non-compliant Code Example

_method example_exemplar.example_method(_gather args)
    ## @param {sw:integer...} args
_endmethod

Compliant Code Example

_method example_exemplar.example_method(_gather args)
    ## @param {sw:integer} args
_endmethod

Variadic on @slot: a slot holds one value; declare a collection type for many.

Non-compliant Code Example

## @slot {sw:integer...} values
def_slotted_exemplar(:example_exemplar,
    {
        {:values, _unset}
    })
$

Compliant Code Example

## @slot {sw:simple_vector} values
def_slotted_exemplar(:example_exemplar,
    {
        {:values, _unset}
    })
$
