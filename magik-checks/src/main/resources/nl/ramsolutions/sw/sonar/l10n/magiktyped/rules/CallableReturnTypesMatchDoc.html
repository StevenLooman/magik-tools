Callable return types match doc

Explanation

Verifies that the @return type annotations in a callable's documentation match its reasoned return types. Issues are raised in the following situations:

  • A @return annotation is missing for a return value.
  • A @return annotation is present but the callable returns no value.
  • A @return type does not match the reasoned return type.
  • A @return annotation is present but cannot be verified because the return value comes from a callable with unknown return types.

Return values whose type is unknown (e.g. from an unresolved method call) are skipped for mismatch reporting; those are covered by UndefinedMethodCallResultTypedCheck.

Examples

Type mismatch

_method example_exemplar.example_method()
    ## @return {sw:integer} Returned value.
    _return :symbol
_endmethod

Raises an issue because the callable is documented to return sw:integer but actually returns sw:symbol.

Missing @return

_method example_exemplar.example_method()
    _return 42
_endmethod

Raises an issue because the callable returns a value but has no @return annotation.

Unverifiable @return

_method example_exemplar.example_method()
    ## @return {sw:integer} Returned value.
    _return other_exemplar.unknown_method()
_endmethod

Raises an issue on the @return annotation because the return type cannot be verified: unknown_method() has no known return type.
