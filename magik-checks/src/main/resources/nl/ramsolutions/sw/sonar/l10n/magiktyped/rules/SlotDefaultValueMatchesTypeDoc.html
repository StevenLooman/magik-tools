Checks that the default value given to a slot in def_slotted_exemplar() matches the type declared for that slot in its @slot type documentation. A mismatch means the slot is initialized with a value the documentation says it cannot hold. When a slot may be unset, declare sw:unset as one of its types.

Non-compliant Code Example

## @slot {sw:integer} slot1
def_slotted_exemplar(:test_exemplar, {{:slot1, _unset}})

Compliant Code Example

## @slot {sw:integer|sw:unset} slot1
def_slotted_exemplar(:test_exemplar, {{:slot1, _unset}})
