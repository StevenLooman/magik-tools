Binary operator type mismatch

Explanation

_method a.b
    _local x << :symbol
    _local y << :symbol + 1
    x +<< 1
_endmethod

In the above example, both 

:symbol + 1
and 
x +<< 1
apply 
+
to 
sw:symbol
and 
sw:integer
, which is not a defined binary operation. This will result in a runtime error.
