Argument type does not match parameter type

Explanation

_method a.m(param1, param2)
    ## @param {sw:integer} param1
    ## @param {sw:integer} param2
_endmethod
$

_block
    a.m(1, :a)
_endblock
$

The method 

a.m()
is called with arguments of type 
sw:integer
and 
sw:symbol
, while the method expects 
sw:integer
twice, as per method doc.
